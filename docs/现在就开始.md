# 🚀 现在就开始 - Skill Hub 启动指南

## ⚠️ 最重要的一件事

**必须在项目根目录运行所有命令！**

打开命令提示符或 PowerShell，输入：

```cmd
cd E:\projects\AIs\skill-creator
```

确认你看到的提示符是：
```
E:\projects\AIs\skill-creator>
```

而不是：
```
E:\projects\AIs\skill-creator\backend>  ← 错误！
```

---

## 🎯 三步启动（首次使用）

### 第 1 步：确认配置文件

```cmd
# 查看 .env 文件是否存在
dir .env
```

如果不存在，复制示例文件：
```cmd
copy .env.example .env
```

### 第 2 步：启动 Docker 服务

```cmd
docker-compose -f docker-compose.simple.yml up -d
```

等待 5-10 秒让服务启动。

### 第 3 步：启动开发服务器

```cmd
uv run dev
```

完成！现在访问：
- **API 文档**: http://localhost:8000/docs
- **MinIO 控制台**: http://localhost:9001 (minioadmin / minioadmin123)


## ❌ 遇到错误？

### 错误 1: 找不到 docker-compose.simple.yml

**你看到**:
```
open E:\projects\AIs\skill-creator\backend\docker-compose.simple.yml: The system cannot find the file specified.
```

**原因**: 你在 backend 目录运行命令

**解决**:
```cmd
cd E:\projects\AIs\skill-creator
uv run dev
```

---

### 错误 2: Field required (SECRET_KEY, DATABASE_URL...)

**你看到**:
```
ValidationError: 10 validation errors for Settings
SECRET_KEY
  Field required
```

**原因**: .env 文件不存在或未加载

**解决**:
```cmd
# 检查文件
dir .env

# 如果不存在，复制模板
copy .env.example .env

# 手动复制到 backend
copy .env backend\.env

# 重新启动
uv run dev
```

---

### 错误 3: Extra inputs are not permitted (DEBUG)

**你看到**:
```
ValidationError: 1 validation error for Settings
DEBUG
  Extra inputs are not permitted
```

**状态**: 已修复 ✅

这个问题已经在代码中修复了。如果仍然出现，请确保你的 `backend/app/core/config.py` 包含：

```python
class Config:
    extra = "ignore"
```

---

### 错误 4: 端口被占用

**MinIO 端口 (9000/9001)**:
```cmd
# 停止 Docker 服务
docker-compose -f docker-compose.simple.yml down

# 重新启动
docker-compose -f docker-compose.simple.yml up -d
```

**FastAPI 端口 (8000)**:
```cmd
# 查看占用进程
netstat -ano | findstr :8000

# 停止进程（记下 PID）
taskkill /PID <PID> /F
```
